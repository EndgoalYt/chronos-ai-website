Contact

Reaching the project.

There is no contact form here. The project has one inbox, read directly, and a public issue tracker if you would rather the answer be visible to others.

Ways to reach the project

01

Email the project

The official address. Opens Gmail's compose window. The simplest route for anything that does not belong in a public issue.

chronosai.team@gmail.com

02

Report a problem or request something

The project is public, and its issue tracker is the one place a report can be read, answered, and found again.

Open an issue on the repository with what happened, what you expected, and the browser and model involved. Reports with those three things are the ones that can actually be acted on.

Open an issue on GitHub

03

Raise it in the conversation

For something about how the assistant behaves, the conversation itself is the most direct route.

Describe the behaviour in the assistant and it will be addressed in the exchange rather than deferred to a queue.

04

Questions about the project

Most answers are already written down.

Cost, accounts, local models, offline use, platform support, and what is still being built are covered on the FAQ page.

What is not offered

Stated plainly.

So there is no expectation of a reply that cannot come.

Sales or billing
There is nothing to buy, so there is no billing contact.
Account recovery
There are no accounts, so there is nothing to recover.
Priority support
Support is not tiered, because there are no tiers.
Partnership enquiries
The project is independent and is not seeking commercial arrangements.
