Get Chronos

Start in the browser. Nothing to install.

Chronos runs as a web application. There is no download to complete before you can use it, and no installer to verify.

Install as an app

Optional, not required.

A supported browser can install Chronos as a standalone window, which behaves like a normal application and can cache the interface for offline loading.

On desktop browsers, use the install control in the address bar, or the install button in the footer of the home page when the browser offers one. On iPhone and iPad, open the page in Safari, tap Share, and choose Add to Home Screen.

Installing changes nothing about the assistant itself. The same capabilities, the same absence of an account, and the same lack of a price.

Generating a response still requires a model — either local, which needs no network, or a remote provider, which does.

Before you start

What to have ready.

A browser
A current version of any mainstream browser. This is the only hard requirement.
A model
Local, if your hardware can run a compatible model; otherwise an online provider you have chosen. Chronos does not bundle a model.
Memory, for local use
Local models are limited by RAM and processor more than anything else. The model's own requirements are the ones that matter.
A network, for remote use
Only needed if you choose an online provider. Local use works without one.
