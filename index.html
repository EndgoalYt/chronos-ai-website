GOOD QUESTIONS

Frequently asked.

Will Chronos AI work offline?

Local chat can work offline when a compatible model and all required files are already installed. Online providers and cloud-based image generation require an internet connection.

Is Chronos AI free?

This website is designed to be hosted using free services. Model providers, cloud services, and future distribution costs may have separate terms or limits.

Can I download it right now?

The website is ready to connect to a release, but the installer link is intentionally disabled until a real, tested build is published.

Will every feature work on every computer?

No. Supported features depend on the operating system, hardware, installed models, and connected AI providers. Platform-specific support will be documented for each release.
